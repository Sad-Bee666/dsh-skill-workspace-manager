# 归属与分类规范

## 分类口径（8 段式，沿用“大学生职业规划会话”的交付汇总）

| 编号 | 分类 | 收纳内容 | 常见文件 |
| --- | --- | --- | --- |
| 01 | 最终交付 | 可直接交给用户/评委/老师的成品 | .docx/.pdf/.pptx/.html、定稿 md |
| 02 | 过程版本 | 成品的中间修订版 | 旧版 .pptx、另一文件名的 .docx |
| 03 | 策划文档 | 方案、设计说明、需求、大纲 | design_spec.md、spec_lock.md |
| 04 | 调研资料 | 原始素材、参考资料、检索缓存 | PDF、扫描图、抓取的 txt |
| 05 | 源码与工作区 | 工程源码、项目目录 | src/、package 目录 |
| 06 | 预览与校验 | 预览图、校验/审查输出 | 逐页 PNG、verify.json、裁剪图 |
| 07 | 脚本 | 一次性脚本与工具 | build.py、probe.mjs、*.ps1 |
| 08 | 其他 | 杂项 | 备份配置、会话导出片段 |

只创建非空目录；每个会话目录下必须有 README_文件说明.md（原路径 → 归档路径 → 规模 → 状态 + 保留原位表）。

## 归属判定顺序（从强到弱）

1. **直接写入证据**：转录里 write / edit / ops_replace / str_replace_editor 的 file_path。
2. **代码内路径**：run_code / bash 参数字符串里出现的绝对路径（正则提 `[A-Za-z]:[\\/][^\r\n"'<>|?*]*`）。
3. **时间窗**：文件 mtime 落在某会话 [created, last] 内，且该区间无其他会话重叠。
4. **目录聚类**：同一顶层目录内多数文件归同一会话，整棵复制。
5. 都判不出 → 00_未归属_历史会话与外部资源。

## 子代理与跨工作区
- delegationDepth=1 的会话（UUID 不带 session- 前缀）是子代理，产物并入父会话目录，不单列。
- 同一磁盘工作区可能对应多个 session store（子目录被单独作为工作区打开过），扫描时要覆盖全部 store。
- 会话 store 目录名是 cwd 的编码，例如 D:\myproject → --D-myproject--。

## 保留原位的典型对象
| 对象 | 判定 |
| --- | --- |
| venv / Python 安装包残留 | 不复制；确认 PATH 与 where python 不指向它后可删 |
| 插件源码 + 补丁脚本 | 不复制；删前说明「将来重打补丁需重新 clone」 |
| 插件市场探包工作区 | 不复制；其中的大 payload 单文件可单独删 |
| 安装配置备份 *.before-* | 小、但要留：插件装坏时的回滚点 |
| .git | 不进归档；克隆得到的仓库可按“可重新获取”处理 |
